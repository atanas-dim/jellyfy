## Fixed

- Preserve native `light-dark()` foreground selection inside nested light and dark themes when CSS compilers generate older-browser compatibility code.
- Keep the existing color customization variables and local Tailwind override behavior.
- Allow layered material-setting overrides regardless of stylesheet order.
- Resolve elevation on component faces so section and instance overrides change their shadows.

## Changed

- Use translucent white highlights and black shades for button, field, and bump lighting, with adjusted strengths for light and dark themes. Lighting blends with the fill without depending on the slot solid’s lightness.

- Document the supported browser minimums: Chrome and Edge 123, Firefox 120, and Safari / iOS Safari 17.5. Native `light-dark()` support is required for default slot foreground colors.
