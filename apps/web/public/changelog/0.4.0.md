## Added

- Separate material, motion, and component stylesheet imports alongside the whole-library stylesheet.
- Dedicated icon button and bump button components.
- Independent solid, control-content, and surface-content colors for each color slot.

## Breaking changes

- Replace the previous component styling with the new design system. Review component classes and customization variables when upgrading.
- Rename the direct runtime file from `jellyfy.js` to `index.js`. The `import { startJellyfy } from "jellyfy"` package import remains available.
- Remove the `jellyfy/plugin.js` export.
