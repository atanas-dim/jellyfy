# Jellyfy

Soft controls from one material. The controls are CSS classes. A short script runs the press, the loading lights, and the slider fill.

## This app

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

- `/` is the introduction.
- `/set` is every component, color, and size.
- `/docs` is the guide.
- `/design-system` is the specification, with one example of each component.

## The package

The library lives in `packages/jellyfy`. Install and import instructions are in `packages/jellyfy/README.md`. That file is the page npm shows.

The specification is `docs/design-system.md`. The remaining release steps are `docs/go-live.md`.
